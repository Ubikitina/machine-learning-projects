# aprendizaje-automatico

Este repositorio contiene los trabajos realizados como parte del **Máster Universitario en Ingeniería y Ciencia de Datos** de la **UNED**, específicamente para la asignatura **Aprendizaje Automático I**

El objetivo de este repositorio es almacenar y organizar los trabajos prácticos realizados durante el curso, utilizando herramientas y tecnologías de aprendizaje automático como **scikit-learn**, **Keras** y **TensorFlow**.

## Estructura del repositorio

- **Actividad 1**: Implementación de **Naive Bayes**, **K-NN** y **Árboles de Decisión**.
- **Actividad 2**: Diseño y entrenamiento de **Redes Neuronales**.
- **Actividad 3**: Aplicación de **Máquinas de Vectores Soporte (SVM)**.

A medida que avance el curso, se podrán añadir más carpetas o recursos relacionados con las actividades de la asignatura.

## Requisitos

Las actividades están implementadas en archivos **Jupyter Notebook** (`.ipynb`) y pueden ejecutarse en cualquier entorno compatible. En este caso, se han desarrollado y probado utilizando **Jupyter Notebook** con un entorno de **conda** configurado con las siguientes dependencias:

- **Python 3.9**
- **scikit-learn**
- **Keras**
- **TensorFlow**

Para instalar las dependencias, puedes usar el archivo `environment.yml` (si se proporciona) o instalar manualmente los paquetes necesarios:

```bash
conda create -n aprendizaje_automatico python=3.9 scikit-learn keras tensorflow jupyter -y
conda activate aprendizaje_automatico
```
